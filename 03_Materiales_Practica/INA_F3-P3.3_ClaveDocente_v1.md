# Clave docente de las muestras sintéticas
## Material reservado para facilitación y devolución

**Código:** P3.3  
**Versión:** 1.0 · 28 de agosto de 2026

> Esta clave explica errores plantados de forma deliberada. No representa una lista exhaustiva
> de todas las decisiones posibles. La retroalimentación debe priorizar patrones según el objetivo.

## MS-01 · Correo de seguimiento a un cliente

| Fragmento | Tipo | Explicación breve | Corrección posible |
|---|---|---|---|
| `I write you` | Tiempo verbal y complemento | Un correo en curso requiere presente continuo; *write* necesita `to` | `I am writing to you` |
| `for give information` | Forma verbal | Después de `to` o para expresar finalidad se usa infinitivo | `to give you information` |
| `technician visit` | Pasado simple | La acción ocurrió ayer | `technician visited` |
| `he don't find` | Auxiliar y pasado | El pasado negativo usa `didn't` más forma base | `he didn't find` |
| `in the reception` | Preposición | Para el punto de servicio se prefiere `at` | `at reception` |
| `confirm a new hour` | Selección léxica | En este contexto se confirma una hora o cita | `confirm a new time` |
| `in Monday` | Preposición | Los días usan `on` | `on Monday` |
| `very compromised` | Falso amigo | `compromised` no significa comprometido con el servicio | `committed to solving` |
| `want resolve` | Complementación verbal | `want` requiere infinitivo con `to` | `want to resolve` |

**Prioridad sugerida:** pasado simple y combinaciones verbo–complemento. No corrija todo en una sola devolución.

## MS-02 · Presentación para una entrevista

| Fragmento | Tipo | Explicación breve | Corrección posible |
|---|---|---|---|
| `I have 28 years` | Calco del español | La edad se expresa con `be` | `I am 28 years old` |
| `since five years` | Duración | `for` introduce una cantidad de tiempo | `for five years` |
| `in the nights` | Expresión temporal | La colocación usual es `at night` | `at night` |
| `I work before` | Pasado simple | Se describe una experiencia laboral anterior | `I worked before` |
| `I attend customers` | Falso amigo | `attend` no significa atender clientes | `I helped customers` |
| `person very responsible` | Orden de palabras | El adjetivo precede al sustantivo | `a very responsible person` |
| `I like work` | Forma verbal | `like` admite gerundio o infinitivo | `I like working` |
| `Excel basic` | Orden y categoría | El nivel funciona como adverbio o frase de capacidad | `use basic Excel functions` |
| `the attention to clients` | Colocación | Se prefiere `customer service` | `I like customer service` |

**Prioridad sugerida:** calcos del español y pasado para experiencia laboral.

## MS-03 · Procedimiento para registrar una reservación

| Fragmento | Tipo | Explicación breve | Corrección posible |
|---|---|---|---|
| `agent ask` | Tercera persona | Sujeto singular requiere `-s` | `agent asks` |
| `how many persons` | Selección léxica | `people` es más natural en este contexto | `how many people` |
| `if there is rooms` | Concordancia | El sustantivo plural requiere `are` | `if there are rooms` |
| `customer want` | Tercera persona | Sujeto singular requiere `-s` | `customer wants` |
| `before calculate` | Forma verbal | Después de `before` se usa gerundio o cláusula | `before calculating` |
| `cancellation politic` | Falso amigo | `politic` no significa política institucional | `cancellation policy` |
| `After, request` | Conector | `Afterward` o `Next` funciona mejor solo | `Next, request` |
| `for guarantee` | Forma verbal | La finalidad usa infinitivo | `to guarantee` |
| `his credit card` | Inclusión y referencia | No debe asumirse género | `their credit card details` |
| `when arrives` | Sujeto omitido | El inglés exige sujeto explícito | `when the guest arrives` |

**Prioridad sugerida:** tercera persona singular y formas verbales en secuencias de procedimiento.

## MS-04 · Respuesta a una queja

| Fragmento | Tipo | Explicación breve | Corrección posible |
|---|---|---|---|
| `the inconvenient` | Falso amigo | El sustantivo correcto es `inconvenience` | `the inconvenience` |
| `company send` | Tercera persona | Sujeto singular requiere `-s` | `company sends` |
| `in good conditions` | Colocación | Para estado físico se usa singular | `in good condition` |
| `company have` | Concordancia | Sujeto singular requiere `has` | `company has` |
| `You must send` | Pragmática | Suena demasiado impositivo en una respuesta de servicio | `Please send us` |
| `make a revision` | Calco | En servicio se usa `review` como verbo | `we will review the case` |
| `change it for` | Selección léxica | Para productos se usa `replace` | `replace it with` |
| `your comprehension` | Falso amigo | Se agradece la comprensión con `understanding` | `your understanding` |
| `for prefer` | Forma verbal | Después de `for` se usa gerundio | `for choosing our company` |

**Prioridad sugerida:** falsos amigos y tono de atención al cliente.

## MS-05 · Correo sobre un cambio en una entrega

| Fragmento | Tipo | Explicación breve | Corrección posible |
|---|---|---|---|
| `delivery programmed` | Falso amigo/colocación | Para agenda se usa `scheduled` | `delivery scheduled` |
| `confirm us` | Complementación | `confirm` recibe el dato o usa `to us` | `confirm whether` |
| `available for receive` | Forma verbal | Después de preposición se usa gerundio | `available to receive it` |
| `the damages this can cause` | Selección léxica | `damage` suele ser incontable; aquí conviene `disruption` | `the disruption this may cause` |
| `For avoid` | Forma verbal | La finalidad usa infinitivo | `To avoid` |
| `any consultation` | Falso amigo | En correo se usa `questions` o `queries` | `any questions` |

**Prioridad sugerida:** colocaciones profesionales y complementación verbal. El texto ya cumple razonablemente su propósito.

## MS-06 · Procedimiento ante una llamada difícil

| Fragmento | Tipo | Explicación breve | Corrección posible |
|---|---|---|---|
| `is listen` | Forma verbal | Después de `is` se requiere infinitivo en esta estructura | `is to listen` |
| `what is the principal problem` | Orden y falso amigo | En pregunta indirecta no hay inversión; `main` es más natural | `what the main problem is` |
| `customer finish` | Tercera persona | Sujeto singular requiere `-es` | `customer finishes` |
| `actions can do` | Sujeto omitido | Debe indicarse quién realizará la acción | `actions the agent can take` |
| `not promise` | Forma verbal | Después de `should` se mantiene forma base con `not` | `should not promise` |
| `depends of` | Preposición | La combinación correcta es `depend on` | `depends on` |
| `in how much time` | Expresión temporal | Se prefiere `within what time` o un plazo concreto | `within what time frame` |
| `Before finish` | Forma verbal | Después de preposición se usa gerundio | `Before finishing` |
| `another doubt` | Falso amigo | En servicio se pregunta por `questions` | `another question` |
| `permits that` | Calco | Se prefiere `allows someone to` | `allows the next agent to understand` |

**Prioridad sugerida:** formas verbales después de preposiciones y calcos sintácticos.

## Orientación para la devolución pública

1. Seleccione un patrón que aparezca más de una vez.
2. Explique el efecto comunicativo, no solo la regla.
3. Compare un comentario genérico con uno que exige una acción.
4. Muestre una microrremediación que no reescriba el texto completo.
5. Recuerde que una salida de IA requiere validación lingüística docente.
