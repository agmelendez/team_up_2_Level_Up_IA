# Presentaciones HTML para revisión

## Archivos

- `INA_F2-P2.1_Bloque1_PanoramaMetodo_v2.html`: 20 láminas para el Bloque 1.
- `INA_F2-P2.3_Bloque3_ModalidadEducativa_v2.html`: 15 láminas para el Bloque 3.
- `INA_F2-P2.4_Bloque4_IALocal_v2.html`: 11 láminas para el Bloque 4.
- `presentaciones.css`: sistema visual compartido en formato 16:9.
- `presentaciones-datos.js`: contenido, notas y fuentes de las tres presentaciones.
- `presentaciones.js`: navegación, progreso, notas, fuentes, vista general e impresión.

Los archivos también funcionan de manera independiente, pero ya están integrados al portal mediante `herramientas.html#slides`. La portada `index.html` ofrece accesos directos en el hero y en el directorio de herramientas.

## Uso

Abra cualquiera de los tres archivos HTML en un navegador moderno. Para presentar, active la pantalla completa con el botón correspondiente o con la tecla `F`.

### Controles

| Acción | Tecla |
| --- | --- |
| Siguiente lámina | Flecha derecha, flecha abajo, espacio o Avance de página |
| Lámina anterior | Flecha izquierda, flecha arriba o Retroceso de página |
| Primera lámina | Inicio |
| Última lámina | Fin |
| Notas del facilitador | N |
| Fuentes y límites | S |
| Vista general | O |
| Pantalla completa | F |
| Cerrar panel | Escape |

En una pantalla táctil, deslice horizontalmente para cambiar de lámina.

## Impresión y PDF

El estilo de impresión genera una lámina 16:9 por página. Use la función de impresión del navegador y seleccione Guardar como PDF si necesita una copia de respaldo.

## Criterio de evidencia

Las afirmaciones nuevas se apoyan en documentos del corpus local de la Biblioteca RAG. Cada lámina pertinente muestra una referencia breve en el pie. La tecla `S` abre el detalle de la fuente y los límites de transferencia.

Las presentaciones evitan afirmar que:

- una herramienta produce aprendizaje por sí sola;
- una transcripción equivale a una evaluación fonética;
- un estudio universitario de evaluación oral valida el uso en todos los contextos del INA;
- ejecutar un modelo en modo avión demuestra privacidad completa;
- un modelo local elimina la necesidad de revisar permisos, registros, licencia, actualizaciones y procedencia.
